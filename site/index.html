What it does with your music

It reads the song from Windows, not from Spotify's servers. Top Display asks Windows which song the Spotify desktop app is playing. It never signs in to Spotify.

It sends the artist, title, album and length to a public lyrics database. That's how it finds the lyrics, from lrclib.net, with lyrics.ovh as a backup. Nothing else leaves your computer. Read the privacy statement.

Your settings stay on your PC. No account, no tracking, no ads. The code is public, so you can check all of this.

Questions

Does it work with the Spotify web player or my phone?

No. Top Display reads the song from Windows, and only the Spotify desktop app reports it there. It doesn't see what you play on your phone or in a browser.

Why does Windows warn me before installing?

The installer isn't code-signed yet, and Windows warns about any file from a publisher it doesn't know. Check the SHA-256 above against your download to know it's unchanged. The source is public, and the installer is built from it.

Why are there no lyrics for some songs?

The lyrics come from a community database, lrclib.net. Newer, rarer or instrumental songs may not be in it yet. When that happens the window says so, and tries again later.

What can I change?

Unlock it with Ctrl+Alt+L and click the gear. You can pick the lyric animation, change both keyboard shortcuts, reset the window, and open the settings folder. The slider along the top sets how see-through the background is. At zero, it's just the text.

Does it work over games?

It stays on top of normal windows, including borderless windowed games. A game running in exclusive fullscreen can hide any overlay, this one included.

Which versions of Windows does it run on?

It's built for Windows 11 and should run on Windows 10, since it uses the system media session. It has only been tested on Windows 11 so far.

How do I uninstall it?

Open Settings, then Apps, find Top Display and uninstall. It asks whether to delete your settings and saved lyrics too.

Is it connected to Spotify?

No. Top Display is an independent project. It isn't made, endorsed or supported by Spotify. It's free software under the GPL-3.0 licence.
